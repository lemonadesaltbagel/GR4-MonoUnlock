흑백 전용 GR IV에는 고유한 흑백 룩이 들어 있습니다. GR4-MonoUnlock은 이 여섯
가지 룩을 모두 표준 GR IV로 가져와, **화상 컨트롤**, **RAW Development**, 그리고
(그중 세 가지는) **동영상** 모드에서 바로 사용할 수 있게 합니다. 카메라의 나머지는
모두 그대로 유지되며, 언제든지 공식 펌웨어로 되돌릴 수 있습니다.

이 저장소에는 RICOH 펌웨어가 들어 있지 않습니다. 공식 펌웨어는 직접 RICOH에서
다운로드하고, 함께 제공되는 도구가 본인의 컴퓨터에서 그 파일을 잠금 해제된 버전으로
바꿉니다.

> [!WARNING]
> **비공식이며, 사용에 따른 책임은 본인에게 있습니다.** RICOH IMAGING이 만들거나 보증한 것이 아닙니다.
> 수정된 펌웨어를 설치하면 보증을 받지 못할 수 있습니다. 먼저
> [시작하기 전에](#시작하기-전에)와 [위험](#위험)을 읽어 주세요.

## 설치 결과

설치하면 화상 컨트롤 목록의 끝부분이 다음과 같이 됩니다. 화상 컨트롤과 표준을 제외한
메뉴 이름은 카메라를 영어로 설정했을 때의 표시대로 적었습니다.

| 표시 이름 | 룩 | 사진 | 동영상 |
| --- | --- | :---: | :---: |
| HDR Tone | (기존 컬러 룩) | ✓ | |
| **표준** | 흑백 표준 | ✓ | ✓ |
| **Solid** | 흑백 Solid | ✓ | ✓ |
| **Soft** | 흑백 Soft | ✓ | |
| **High Contrast** | 흑백 High Contrast | ✓ | ✓ |
| **Grainy** | 흑백 Grainy | ✓ | |
| **HDR Tone** | 흑백 HDR *(실험적)* | ✓ | |

- 같은 룩을 **RAW Development**(카메라 내 RAW 현상)에서도 사용할 수 있습니다.
- 새 룩은 각각 자체 기본 설정으로 시작하며, 기존 룩과 마찬가지로 **모든 슬라이더가
  0**입니다.
- 기존 룩은 모두 그대로입니다.

아이콘에도 이 룩들이 나타나 있습니다. 조리개의 날 하나하나가 룩 하나이며, 맨 위의
표준에서 시작해 시계 방향으로 이 목록의 순서를 따릅니다.

## 시작하기 전에

- **카메라:** RICOH GR IV(표준 컬러 모델). 다른 모델은 지원하지 않습니다.
- **카메라가 이미 펌웨어 1.11이어야 합니다.** 카메라의 설정 메뉴에서 버전을
  확인하세요.
  - 이전 버전: 먼저 RICOH 공식 파일로 일반적인 방법에 따라 1.11로 업데이트하세요.
  - 더 새로운 버전: **이 도구를 사용하지 마세요.** 1.11만 지원합니다.
- **공식 펌웨어 파일.** RICOH IMAGING의 공식 GR IV 지원 페이지에서 **펌웨어 버전 1.11**을
  다운로드하세요. 필요하면 압축을 풀어 **`fwdc248b.bin`** 파일을 얻으세요.
- **완전히 충전된 배터리.** 펌웨어 업데이트 중에는 절대 전원이 끊기면 안 됩니다.
- 포맷해도 되는 **SD 카드**.
- **Python 3.8 이상.** macOS와 대부분의 Linux 시스템에는 이미 설치되어 있습니다.
  Windows에서는 python.org에서 설치하세요. 그 밖에는 아무것도 필요하지 않습니다.
- 다시 설정하고 싶지 않은 사용자 설정(C1, C2, …)은 적어 두세요.

## 펌웨어 만들기

이 폴더에서 터미널을 열고 다음을 실행하세요(공식 파일을 저장한 경로를 사용하세요).

```sh
python3 gr4_monounlock.py patch ~/Downloads/fwdc248b.bin
```

Windows에서:

```bat
py gr4_monounlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

도구는 먼저 제공한 파일이 진짜 공식 1.11 파일인지 확인한 다음, 잠금 해제된 펌웨어를
만들고 검사합니다. 모든 것이 정상이면 다음과 같이 끝납니다.

```
wrote output/fwdc248b.bin  (SHA-256 4c04b48c65897f2edd028df0f5e04666ca241488c81502bae0f34e040ee454eb)
```

문제가 있으면(예: 다른 펌웨어 버전이거나 다운로드가 손상된 경우) `refused: …`를
출력하고 **아무것도 쓰지 않습니다**.

## 카메라에 설치하기

### 1. SD 카드에 복사하기

1. **카메라에서 SD 카드를 포맷하세요.**
2. **`output/fwdc248b.bin`**을 카드의 **최상위 위치**에 복사하세요. 폴더 안에 넣지
   말고, 이름은 정확히 `fwdc248b.bin` 그대로 두세요.

### 2. 카메라 업데이트하기

1. 완전히 충전된 배터리와 SD 카드를 넣으세요.
2. RICOH 공식 GR IV 펌웨어 업데이트 안내에 따라 카메라의 설정 메뉴에서 펌웨어
   업데이트를 시작하세요.
3. **카메라에 버전 1.11에서 버전 1.11로 업데이트한다고 표시됩니다.** 이는 정상입니다.
   잠금 해제된 펌웨어는 버전 번호를 그대로 유지합니다. 업데이트를 확인하세요.

> [!CAUTION]
> **업데이트가 끝나고 카메라가 다시 시작될 때까지 카메라 전원을 끄거나, 배터리
> 덮개나 카드 덮개를 열거나, 카드를 빼지 마세요.**

### 3. 촬영하기

- **화상 컨트롤**을 여세요. 새 룩은 첫 번째 “HDR Tone” 다음에 있습니다.
- 펌웨어 버전은 여전히 **1.11**로 표시됩니다. 정상입니다.
- 업데이트가 실수로 다시 시작되지 않도록 카드에서 `fwdc248b.bin`을 삭제하세요(또는
  카드를 포맷하세요).

### 공식 펌웨어로 되돌리기

1~2단계를 RICOH의 **공식** `fwdc248b.bin`으로 다시 하세요. 카메라에 다시
**1.11 → 1.11**이 표시됩니다. 확인하면 카메라가 원래 상태로 돌아갑니다.

## 알아 두면 좋은 점

- **“표준”과 “HDR Tone” 항목이 각각 두 개.** 흑백 표준과 HDR 룩은 컬러 룩과 같은 이름과
  아이콘을 사용합니다. 새 룩은 첫 번째 “HDR Tone” 다음의 항목입니다.
- **Soft, Grainy, HDR은 사진 전용입니다.** 흑백 모델과 마찬가지입니다.
- **흑백 HDR은 실험적입니다.** 설정 화면에서 다른 룩보다 적은 옵션을 제공합니다. 아직
  카메라에서 시험해 보지 않았습니다. 어떻게 작동하는지 알려 주세요.
- **RICOH 공식 업데이트를 설치하면 잠금 해제가 사라집니다.** 펌웨어 전체를 교체하기
  때문입니다.
- **1.11의 표준 GR IV 전용입니다.** 다른 모델에는 절대 이 파일을 설치하지 말고, 다른
  펌웨어 버전에는 이 도구를 사용하지 마세요.
- **카메라를 수리에 보내기 전에** 공식 펌웨어로 되돌리세요.

### 펌웨어 파일 확인

펌웨어 파일을 카드에 복사하기 전에 확인하세요.

```sh
python3 gr4_monounlock.py check path/to/fwdc248b.bin
```

이 명령은 파일이 공식 1.11인지, 이 도구로 만든 잠금 해제 버전인지, 아니면 다른
것인지 알려 줍니다.

## 위험

- 카메라는 정상적인 펌웨어 파일과 손상된 파일을 구별하지 못합니다. 도구가 쓴(또는
  `check`로 확인한) 파일만 카드에 복사하세요.
- 업데이트가 중단되거나 펌웨어 파일이 시작되지 못하면, 카메라가 다시 업데이트 기능에
  들어가지 못할 수 있으며, 그러면 RICOH 서비스가 필요합니다. 테스트 중에는 이런 일이
  없었지만, 가능성을 배제할 수는 없습니다.
- 카메라 고유의 캘리브레이션 데이터는 건드리지 않습니다.

## 테스트 현황

| 항목 | 상태 |
| --- | --- |
| 업데이트가 받아들여짐. 표준, Soft, High Contrast, Solid가 나타나고 작동함 | GR IV 1.11에서 테스트함 |
| 공식 1.11로 되돌리면 카메라가 완전히 복원됨 | GR IV 1.11에서 테스트함 |
| Grainy | GR IV 1.11에 설치되고 시작된 테스트 빌드에 포함됨 |
| 흑백 HDR | 아직 카메라에서 시험해 보지 않음 |
| 도구가 테스트된 펌웨어를 정확히 재현함 | 테스트함 |
