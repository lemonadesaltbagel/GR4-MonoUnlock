只拍黑白的 GR IV 机型自带一套专属的黑白风格。GR4-MonoUnlock 把这六种风格全部带到标准版 GR IV 上，可以直接在 **影像控制** 和 **RAW Development** 中使用，其中三种还可以在 **视频** 模式中使用。相机上的其他一切都保持原样，你可以随时恢复官方固件。

本仓库不包含任何 RICOH 固件。官方固件由你自己从 RICOH 下载，附带的工具会在你自己的电脑上把它转换成解锁版本。

> [!WARNING]
> **非官方，风险自负。** 并非由 RICOH IMAGING 制作或认可。
> 安装修改过的固件可能导致失去保修。请先阅读[开始之前](#开始之前)和[风险](#风险)。

## 安装后的效果

安装后，**影像控制** 列表的末尾如下。下表及下文中的菜单名称（影像控制、标准除外）均按相机设为英语时的显示给出。

| 显示为 | 风格 | 照片 | 视频 |
| --- | --- | :---: | :---: |
| HDR Tone | （你现有的彩色风格） | ✓ | |
| **标准** | 黑白标准 | ✓ | ✓ |
| **Solid** | 黑白 Solid | ✓ | ✓ |
| **Soft** | 黑白 Soft | ✓ | |
| **High Contrast** | 黑白 High Contrast | ✓ | ✓ |
| **Grainy** | 黑白 Grainy | ✓ | |
| **HDR Tone** | 黑白 HDR *（实验性）* | ✓ | |

- 同样的风格也可以在 **RAW Development**（相机内 RAW 处理）中使用。
- 每种新风格打开时都使用它自己的默认设置，**所有滑块均为 0**，与原有风格一样。
- 你现有的所有风格保持不变。

图标也展示了它们：光圈的每一片叶片代表一种风格，按此列表的顺序，从顶部的标准开始顺时针排列。

## 开始之前

- **相机：** RICOH GR IV（标准彩色型号）。不支持其他型号。
- **相机必须已升级到固件 1.11。** 请在相机的设置菜单中查看版本。
  - 较旧版本：先用 RICOH 的官方文件按常规方式更新到 1.11。
  - 较新版本：**不要使用本工具。** 它只支持 1.11。
- **官方固件文件。** 从 RICOH IMAGING 官方的 GR IV 支持页面下载 **固件版本 1.11**。如有需要请解压，直到得到文件 **`fwdc248b.bin`**。
- **充满电的电池。** 固件更新过程中绝不能断电。
- **一张可以格式化的 SD 卡。**
- **Python 3.8 或更高版本。** macOS 和大多数 Linux 系统已自带；在 Windows 上，请从 python.org 安装。不需要其他任何东西。
- 记下你不想重新设置的自定义设置（C1、C2 等）。

## 制作固件

在此文件夹中打开终端并运行（请换成你保存官方文件的路径）：

```sh
python3 gr4_monounlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_monounlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具会先确认你提供的是真正的官方 1.11 文件，然后生成解锁固件并进行检查。一切正常时，最后会显示：

```
wrote output/fwdc248b.bin  (SHA-256 4c04b48c65897f2edd028df0f5e04666ca241488c81502bae0f34e040ee454eb)
```

如果出现问题（例如固件版本不同，或下载的文件已损坏），工具会显示 `refused: …`，并且 **不写入任何内容**。

## 安装到相机

### 1. 复制到 SD 卡

1. **在相机中格式化 SD 卡。**
2. 把 **`output/fwdc248b.bin`** 复制到存储卡的 **根目录**：不要放进文件夹，文件名必须保持为 `fwdc248b.bin`。

### 2. 更新相机

1. 装入充满电的电池和 SD 卡。
2. 按照 RICOH 官方 GR IV 固件更新说明，从相机的设置菜单启动固件更新。
3. **相机会显示从版本 1.11 更新到版本 1.11。** 这是正常的：解锁固件保留了版本号。请确认更新。

> [!CAUTION]
> **在更新完成且相机重新启动之前，不要关闭相机、不要打开电池仓盖或存储卡盖，也不要取出存储卡。**

### 3. 拍摄

- 打开 **影像控制**：新风格位于第一个“HDR Tone”之后。
- 固件版本仍显示 **1.11**。这是正常的。
- 从存储卡中删除 `fwdc248b.bin`（或格式化存储卡），以免意外再次启动更新。

### 恢复官方固件

改用 RICOH 的 **官方** `fwdc248b.bin`，重复第 1–2 步。相机同样会显示 **1.11 → 1.11**；确认后，相机即恢复为原厂状态。

## 须知

- **两个“标准”和两个“HDR Tone”项目。** 黑白标准和黑白 HDR 风格使用与彩色风格相同的名称和图标。新增的是第一个“HDR Tone”之后的项目。
- **Soft、Grainy 和 HDR 只能用于拍照**，与黑白型号相同。
- **黑白 HDR 是实验性的。** 它的设置画面提供的选项比其他风格少。它尚未在相机上试过；请反馈它的表现。
- **RICOH 官方更新会移除解锁。** 它会替换整个固件。
- **仅适用于固件 1.11 的标准版 GR IV。** 切勿在其他型号上安装该文件，也不要将本工具用于其他固件版本。
- **送修相机之前，** 请恢复官方固件。

### 检查固件文件

将任何固件文件复制到存储卡之前：

```sh
python3 gr4_monounlock.py check path/to/fwdc248b.bin
```

它会告诉你该文件是官方 1.11、由本工具制作的解锁版本，还是其他文件。

## 风险

- 相机无法区分完好的固件文件和损坏的文件。只把工具写出的（或经 `check` 确认的）文件复制到存储卡。
- 如果更新被中断，或固件文件无法启动，相机可能无法再进入更新功能，届时就需要 RICOH 维修。测试中没有发生过这种情况，但不能排除。
- 相机自身的校准数据不会被改动。
