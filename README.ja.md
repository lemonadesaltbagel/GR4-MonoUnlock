モノクロ専用のGR IVには、独自の白黒ルックが搭載されています。GR4-MonoUnlockは、その6つすべてを標準のGR IVに搭載し、**イメージコントロール**、**RAW Development**、そして（そのうち3つは）**動画**モードですぐに使えるようにします。カメラのそれ以外の部分はすべてそのままで、いつでも公式ファームウェアに戻せます。

このリポジトリにRICOHのファームウェアは含まれていません。公式ファームウェアはご自身でRICOHからダウンロードしてください。同梱のツールが、お使いのコンピューター上で、それをアンロック版に作り変えます。

> [!WARNING]
> **非公式です。ご自身の責任でお使いください。** RICOH IMAGINGが作成・承認したものではありません。改変したファームウェアをインストールすると、保証が受けられなくなる場合があります。先に[はじめる前に](#はじめる前に)と[リスク](#リスク)をお読みください。

## 得られるもの

インストール後、イメージコントロールの一覧の最後は次のようになります。イメージコントロールとスタンダード以外のメニュー名は、カメラを英語に設定したときの表示で記載しています。

| 表示名 | ルック | 静止画 | 動画 |
| --- | --- | :---: | :---: |
| HDR Tone | （今あるカラーのルック） | ✓ | |
| **スタンダード** | スタンダード（モノクロ） | ✓ | ✓ |
| **Solid** | Solid（モノクロ） | ✓ | ✓ |
| **Soft** | Soft（モノクロ） | ✓ | |
| **High Contrast** | High Contrast（モノクロ） | ✓ | ✓ |
| **Grainy** | Grainy（モノクロ） | ✓ | |
| **HDR Tone** | HDR（モノクロ）*（実験的）* | ✓ | |

- 同じルックは**RAW Development**（カメラ内RAW現像）でも使えます。
- 新しいルックはそれぞれ独自の初期設定で始まり、標準のルックと同じく**すべてのスライダーが0**です。
- 既存のルックはすべてそのままです。

アイコンにもそれが表れています。絞りの羽根の1枚1枚が1つのルックで、上のスタンダードから時計回りに、この一覧の順に並んでいます。

## はじめる前に

- **カメラ：** RICOH GR IV（標準のカラーモデル）。ほかの機種には対応していません。
- **カメラのファームウェアがすでに1.11である必要があります。** バージョンはカメラのセットアップメニューで確認してください。
  - 古いバージョンの場合：まずRICOHの公式ファイルを使い、通常の方法で1.11にアップデートしてください。
  - 新しいバージョンの場合：**このツールは使わないでください。** 対応しているのは1.11だけです。
- **公式ファームウェアファイル。** RICOH IMAGINGの公式GR IVサポートページから、**ファームウェアバージョン1.11**をダウンロードします。必要に応じて展開し、**`fwdc248b.bin`** というファイルを取り出します。
- **満充電のバッテリー。** ファームウェアアップデート中に電源が切れることは絶対に避けてください。
- フォーマットしてもよい**SDカード**。
- **Python 3.8以降。** macOSとほとんどのLinuxシステムには、すでに入っています。Windowsでは、python.orgからインストールしてください。ほかには何も必要ありません。
- 設定し直したくないカスタム設定（C1、C2など）は控えておいてください。

## ファームウェアを作る

このフォルダでターミナルを開き、次を実行します（公式ファイルを保存した場所のパスを使ってください）。

```sh
python3 gr4_monounlock.py patch ~/Downloads/fwdc248b.bin
```

Windowsでは：

```bat
py gr4_monounlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

ツールはまず、渡されたファイルが本物の公式1.11ファイルであることを確認し、それからアンロック版ファームウェアを作成して確認します。すべて正しければ、最後は次のようになります。

```
wrote output/fwdc248b.bin  (SHA-256 4c04b48c65897f2edd028df0f5e04666ca241488c81502bae0f34e040ee454eb)
```

問題がある場合（たとえばファームウェアのバージョンが違う、ダウンロードしたファイルが壊れているなど）、ツールは`refused: …`と表示し、**何も書き出しません**。

## カメラに入れる

### 1. SDカードにコピーする

1. **カメラでSDカードをフォーマットします。**
2. **`output/fwdc248b.bin`** をカードの**最上位**にコピーします。フォルダの中には入れず、名前は`fwdc248b.bin`のまま変えないでください。

### 2. カメラをアップデートする

1. 満充電のバッテリーとSDカードを入れます。
2. RICOHの公式GR IVファームウェアアップデート手順に従い、カメラのセットアップメニューからファームウェアアップデートを開始します。
3. **カメラには、バージョン1.11からバージョン1.11へのアップデートと表示されます。** これは想定どおりです。アンロック版ファームウェアはバージョン番号をそのまま保ちます。アップデートを確定してください。

> [!CAUTION]
> アップデートが完了してカメラが再起動するまで、**カメラの電源を切ったり、バッテリーカバーやカードカバーを開けたり、カードを取り出したりしないでください。**

### 3. 撮影する

- **イメージコントロール**を開きます。新しいルックは、最初の「HDR Tone」の後に続きます。
- ファームウェアのバージョンは**1.11**のままです。これは正常です。
- 誤ってアップデートが再び始まらないように、カードから`fwdc248b.bin`を削除してください（またはカードをフォーマットします）。

### 公式ファームウェアに戻す

代わりにRICOHの**公式** `fwdc248b.bin` を使って、手順1〜2を繰り返します。カメラにはまた**1.11 → 1.11**と表示されます。確定すれば、カメラは元の状態に戻ります。

## 知っておきたいこと

- **「スタンダード」と「HDR Tone」が2つずつ。** モノクロのスタンダードとHDRのルックは、カラーのものと同じ名前とアイコンを使います。新しいルックは、最初の「HDR Tone」より後の項目です。
- **Soft、Grainy、HDRは静止画専用です。** モノクロモデルと同じです。
- **モノクロのHDRは実験的です。** 設定画面の選択肢は、ほかのルックより少なくなります。まだカメラで試していません。どのように動作するか、ぜひ報告してください。
- **RICOHの公式アップデートで、アンロックは解除されます。** ファームウェア全体が置き換わるためです。
- **1.11の標準のGR IV専用です。** ほかの機種には絶対にインストールしないでください。また、ほかのファームウェアバージョンでこのツールを使わないでください。
- **カメラを修理に出す前に**、公式ファームウェアに戻してください。

### ファームウェアファイルを確認

ファームウェアファイルをカードにコピーする前に確認してください。

```sh
python3 gr4_monounlock.py check path/to/fwdc248b.bin
```

ファイルが公式の1.11か、このツールで作ったアンロック版か、それ以外かがわかります。

## リスク

- カメラは、正常なファームウェアファイルと壊れたファイルを見分けられません。カードにコピーするのは、このツールが書き出した（または`check`で確認した）ファイルだけにしてください。
- アップデートが中断された場合や、ファームウェアファイルが起動できない場合、カメラがアップデート機能に再びたどり着けなくなり、RICOHの修理が必要になる可能性があります。テストではこのようなことは起きていませんが、可能性は否定できません。
- カメラ固有のキャリブレーションデータには手を加えません。
