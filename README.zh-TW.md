黑白專用的 GR IV 有一套自己的黑白風格。GR4-MonoUnlock 將這六種風格全部帶到標準版 GR IV 上，可在**影像控制**和 **RAW Development** 中使用，其中三種也能在**錄影**模式中使用。相機的其他一切都維持原樣，而且隨時都能還原為官方韌體。

本儲存庫不含任何 RICOH 韌體。官方韌體由您自行從 RICOH 下載，再由隨附的工具在您自己的電腦上，將它轉換成解鎖版本。

> [!WARNING]
> **非官方工具，風險自負。** 並非由 RICOH IMAGING 製作或認可。安裝修改過的韌體可能導致保固失效。請先閱讀[開始之前](#開始之前)和[風險](#風險)。

## 您會得到什麼

安裝後，影像控制清單的最後幾項如下。除了影像控制和標準之外，選單名稱均以相機設為英文時的顯示為準。

| 顯示名稱 | 風格 | 照片 | 影片 |
| --- | --- | :---: | :---: |
| HDR Tone | （您現有的彩色風格） | ✓ | |
| **標準** | 黑白標準 | ✓ | ✓ |
| **Solid** | 黑白 Solid | ✓ | ✓ |
| **Soft** | 黑白 Soft | ✓ | |
| **High Contrast** | 黑白 High Contrast | ✓ | ✓ |
| **Grainy** | 黑白 Grainy | ✓ | |
| **HDR Tone** | 黑白 HDR *（實驗性）* | ✓ | |

- 相同的風格也可在 **RAW Development**（機內 RAW 處理）中使用。
- 每個新風格開啟時都使用自己的預設設定，**所有滑桿皆為 0**，與相機原有的風格一樣。
- 您現有的所有風格都不變。

圖示也呈現了這些風格：光圈的每一片葉片代表一種風格，依此清單的順序，從頂端的標準開始順時針排列。

## 開始之前

- **相機：** RICOH GR IV（標準彩色機型）。不支援其他機型。
- **您的相機必須已更新至韌體 1.11。** 請在相機的設定選單中確認版本。
  - 較舊版本：先以一般方式，用 RICOH 的官方檔案更新至 1.11。
  - 較新版本：**請勿使用本工具。** 本工具只支援 1.11。
- **官方韌體檔案。** 從 RICOH IMAGING 官方 GR IV 支援頁面下載**韌體版本 1.11**。如有需要請解壓縮，直到取得 **`fwdc248b.bin`** 檔案。
- **充飽電的電池。** 韌體更新過程中絕不能斷電。
- **一張可以格式化的 SD 卡。**
- **Python 3.8 或更新版本。** macOS 和大多數 Linux 系統已經內建；在 Windows 上，請從 python.org 安裝。不需要其他任何東西。
- 記下您不想重新設定的自訂設定（C1、C2 等）。

## 製作韌體

在此資料夾中開啟終端機並執行（請使用您儲存官方檔案的路徑）：

```sh
python3 gr4_monounlock.py patch ~/Downloads/fwdc248b.bin
```

在 Windows 上：

```bat
py gr4_monounlock.py patch C:\Users\you\Downloads\fwdc248b.bin
```

工具會先確認您提供的是真正的官方 1.11 檔案，接著產生解鎖韌體並加以檢查。一切正確時，結尾如下：

```
wrote output/fwdc248b.bin  (SHA-256 4c04b48c65897f2edd028df0f5e04666ca241488c81502bae0f34e040ee454eb)
```

若有問題（例如韌體版本不同，或下載的檔案損毀），工具會顯示 `refused: …`，且**不寫入任何內容**。

## 安裝到相機

### 1. 複製到 SD 卡

1. **在相機中格式化 SD 卡。**
2. 將 **`output/fwdc248b.bin`** 複製到記憶卡的**最上層**：不要放進資料夾，檔名必須完全保持 `fwdc248b.bin`。

### 2. 更新相機

1. 裝入充飽電的電池和 SD 卡。
2. 依照 RICOH 官方 GR IV 韌體更新說明，從相機的設定選單開始韌體更新。
3. **相機會顯示從版本 1.11 更新到版本 1.11。** 這是正常的：解鎖韌體保留原本的版本號碼。請確認更新。

> [!CAUTION]
> 在更新完成且相機重新啟動之前，**請勿關閉相機、打開電池蓋或記憶卡蓋，也不要取出記憶卡**。

### 3. 拍攝

- 開啟**影像控制**：新的風格位於第一個「HDR Tone」之後。
- 韌體版本仍顯示 **1.11**，這是正常的。
- 從記憶卡刪除 `fwdc248b.bin`（或格式化記憶卡），以免不小心再次開始更新。

### 還原官方韌體

改用 RICOH 的**官方** `fwdc248b.bin` 重複步驟 1–2。相機同樣會顯示 **1.11 → 1.11**；確認後，相機就恢復原廠狀態。

## 須知

- **兩個「標準」和兩個「HDR Tone」項目。** 黑白標準和 HDR 風格使用與彩色風格相同的名稱和圖示。新的項目是第一個「HDR Tone」之後的那些。
- **Soft、Grainy 和 HDR 只能用於照片**，與黑白機型相同。
- **黑白 HDR 為實驗性功能。** 它的設定畫面提供的選項比其他風格少。它尚未在相機上試過；請回報它的表現。
- **RICOH 官方更新會移除解鎖。** 它會取代整個韌體。
- **只適用於 1.11 的標準版 GR IV。** 絕對不要將此檔案安裝到其他機型，也不要將本工具用於其他韌體版本。
- **送修相機之前**，請先還原官方韌體。

### 檢查韌體檔案

將任何韌體檔案複製到記憶卡之前：

```sh
python3 gr4_monounlock.py check path/to/fwdc248b.bin
```

它會告訴您該檔案是官方 1.11、本工具製作的解鎖版本，還是其他檔案。

## 風險

- 相機無法分辨良好的韌體檔案和損毀的檔案。只將工具寫入的檔案（或經 `check` 確認的檔案）複製到記憶卡。
- 若更新中斷，或韌體檔案無法啟動，相機可能無法再進入更新功能，屆時就需要 RICOH 維修。測試中沒有發生過這種情況，但無法排除。
- 相機本身的校正資料不會被更動。

| 項目 | 狀態 |
